Rust প্রোগ্রামিং ভাষা

slice type

slice (collection-এর একটানা একটি অংশের reference) দিয়ে পুরো collection-এর বদলে collection-এর উপাদানগুলোর একটি একটানা ক্রমকে reference করা যায়। slice এক ধরনের reference, তাই এটি একটি non-owning pointer (ডেটার মালিক নয় এমন pointer)।

slice কেন কাজের, তা বোঝাতে চলুন একটি ছোট প্রোগ্রামিং সমস্যা সমাধান করি: এমন একটি function লিখুন, যা space দিয়ে আলাদা করা শব্দের একটি string নেয় এবং সেই string-এ খুঁজে পাওয়া প্রথম শব্দটি return করে। function-টি string-এ কোনো space খুঁজে না পেলে পুরো string-টিই একটি শব্দ, তাই পুরো string-টিই return করা উচিত। slice ছাড়া আমরা হয়তো function-টির signature এভাবে লিখতাম:

fn first_word(s: &String) -> ?

first_word function-এর parameter একটি &String। আমরা string-টির ownership চাই না, তাই এটা ঠিক আছে। কিন্তু return করব কী? string-এর একটি অংশ নিয়ে কথা বলার কোনো উপায় আসলে আমাদের হাতে নেই। তবে শব্দের শেষ, অর্থাৎ space-এর অবস্থান বোঝানো index-টি আমরা return করতে পারি। চলুন সেটাই চেষ্টা করি, Listing 4-7-এ যেমন দেখানো হয়েছে।

    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return i;
        }
    }

    s.len()

যেহেতু String-এর উপাদানগুলো একটি একটি করে দেখে যাচাই করতে হবে কোনো মান space কি না, তাই as_bytes method ব্যবহার করে আমরা আমাদের String-কে byte-এর একটি array-তে রূপান্তর করব:

এরপর iter method ব্যবহার করে byte-এর array-টির ওপর একটি iterator তৈরি করি:

fn first_word(s: &String) -> usize {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return i;
        }
    }

    s.len()
}

fn main() {}

iterator নিয়ে আমরা অধ্যায় 13-এ আরও বিস্তারিত আলোচনা করব। আপাতত জেনে রাখুন, iter এমন একটি method, যা একটি collection-এর প্রতিটি উপাদান return করে, আর enumerate iter-এর ফলাফলকে মুড়ে প্রতিটি উপাদানকে একটি tuple-এর অংশ হিসেবে return করে। enumerate থেকে return হওয়া tuple-এর প্রথম উপাদান হলো index, আর দ্বিতীয় উপাদান হলো উপাদানটির একটি reference। নিজেরা index হিসাব করার চেয়ে এটি একটু বেশি সুবিধাজনক।

enumerate method যেহেতু একটি tuple return করে, তাই সেই tuple-কে destructure করতে আমরা pattern ব্যবহার করতে পারি। pattern নিয়ে আমরা অধ্যায় 6-এ আরও আলোচনা করব। for loop-এ আমরা একটি pattern দিই, যাতে tuple-এর index-এর জন্য আছে i, আর tuple-এর একক byte-টির জন্য &item। যেহেতু .iter().enumerate() থেকে আমরা উপাদানের একটি reference পাই, তাই pattern-এ & ব্যবহার করি।

for loop-এর ভেতরে byte literal syntax ব্যবহার করে আমরা space বোঝানো byte-টি খুঁজি। space পেলে তার অবস্থান return করি। না পেলে s.len() ব্যবহার করে string-এর দৈর্ঘ্য return করি:

fn first_word(s: &String) -> usize {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return i;
        }
    }

    s.len()
}

fn main() {}

এখন string-এর প্রথম শব্দের শেষের index খুঁজে বের করার একটি উপায় আমাদের আছে, কিন্তু একটি সমস্যা আছে। আমরা আলাদাভাবে একটি usize return করছি, কিন্তু সংখ্যাটি শুধু &String-এর প্রেক্ষাপটেই অর্থবহ। অন্যভাবে বললে, এটি String থেকে একটি আলাদা মান হওয়ায় ভবিষ্যতেও যে এটি বৈধ থাকবে, তার কোনো নিশ্চয়তা নেই। Listing 4-8-এর প্রোগ্রামটি দেখুন, যা Listing 4-7-এর first_word function ব্যবহার করে।

এখন আমরা শুরুর এবং শেষের একটি index-এর হিসাব রাখছি, আর আমাদের কাছে এমন আরও মান আছে, যেগুলো একটি নির্দিষ্ট অবস্থার ডেটা থেকে হিসাব করা হয়েছে, কিন্তু সেই অবস্থার সঙ্গে মোটেও বাঁধা নয়। আমাদের কাছে তিনটি সম্পর্কহীন variable ঘুরে বেড়াচ্ছে, যেগুলো মিলিয়ে রাখতে হবে।

সৌভাগ্যক্রমে, এই সমস্যার একটি সমাধান Rust-এ আছে: string slice।

string slice

string slice (string-এর একটি অংশের reference) হলো একটি String-এর অংশের reference, আর এটি দেখতে এরকম:

পুরো String-এর reference (যেমন s2)-এর বদলে hello হলো String-এর একটি অংশের reference, যা বাড়তি [0..5] অংশে নির্দিষ্ট করা হয়েছে। ব্র্যাকেটের ভেতরে একটি range দিয়ে আমরা slice তৈরি করি: [starting_index..ending_index], যেখানে starting_index হলো slice-এর প্রথম অবস্থান, আর ending_index হলো slice-এর শেষ অবস্থানের চেয়ে এক বেশি।

slice বিশেষ ধরনের reference, কারণ এরা “fat” pointer, অর্থাৎ মেটাডেটাসহ pointer। এখানে মেটাডেটা হলো slice-এর দৈর্ঘ্য। Rust-এর data structure-এর ভেতরে উঁকি দেওয়ার জন্য আমাদের ভিজ্যুয়ালাইজেশন বদলে এই মেটাডেটা দেখতে পারি:

লক্ষ করুন, hello আর world variable দুটিরই একটি ptr আর একটি len field আছে, যেগুলো মিলে heap-এ থাকা string-এর নিচে দাগ দেওয়া অংশগুলো নির্ধারণ করে। এখানে আপনি এটাও দেখতে পাচ্ছেন যে একটি String আসলে দেখতে কেমন: string হলো byte-এর একটি vector (Vec<u8>), যাতে আছে একটি দৈর্ঘ্য len আর একটি বাফার buf, আর বাফারটিতে আছে একটি pointer ptr ও একটি ধারণক্ষমতা cap।

slice যেহেতু reference, তাই এরাও reference করা ডেটার permission বদলায়। যেমন, নিচে লক্ষ করুন, hello-কে s-এর একটি slice হিসেবে তৈরি করার সময় s write আর own permission হারায়:

range syntax

Rust-এর .. range syntax-এ index শূন্য থেকে শুরু করতে চাইলে দুটি বিন্দুর আগের মানটি বাদ দিতে পারেন। অন্যভাবে বললে, এগুলো সমান:

#![allow(unused)]
fn main() {
let s = String::from("hello");

let slice = &s[0..2];
let slice = &s[..2];
}

একইভাবে, আপনার slice-এ যদি String-এর শেষ byte-টি থাকে, তাহলে শেষের সংখ্যাটি বাদ দিতে পারেন। অর্থাৎ এগুলো সমান:

#![allow(unused)]
fn main() {
let s = String::from("hello");

let len = s.len();

let slice = &s[3..len];
let slice = &s[3..];
}

পুরো string-এর একটি slice নিতে দুটি মানই বাদ দিতে পারেন। তাই এগুলো সমান:

#![allow(unused)]
fn main() {
let s = String::from("hello");

let len = s.len();

let slice = &s[0..len];
let slice = &s[..];
}

Note: string slice-এর range index-গুলোকে অবশ্যই বৈধ UTF-8 অক্ষরের সীমানায় পড়তে হবে। একাধিক byte-এর কোনো অক্ষরের মাঝখানে string slice তৈরির চেষ্টা করলে আপনার প্রোগ্রাম একটি error দিয়ে বন্ধ হয়ে যাবে। string slice-এর সঙ্গে পরিচয় করানোর উদ্দেশ্যে এই অংশে আমরা শুধু ASCII ধরে নিচ্ছি; UTF-8 সামলানো নিয়ে আরও বিস্তারিত আলোচনা আছে অধ্যায় 8-এর “string দিয়ে UTF-8 এনকোড করা লেখা রাখা” অংশে।

string slice দিয়ে first_word নতুন করে লেখা

এই সব তথ্য মাথায় রেখে চলুন first_word-কে নতুন করে লিখি, যাতে এটি একটি slice return করে। “string slice” বোঝানো type-টি লেখা হয় &str:

Filename: src/main.rs

fn first_word(s: &String) -> &str {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }

    &s[..]
}

fn main() {}

শব্দের শেষের index আমরা Listing 4-7-এর মতো একইভাবে পাই, অর্থাৎ প্রথম space-টি খুঁজে। space পেলে string-এর শুরু আর space-এর index-কে শুরু ও শেষের index হিসেবে ব্যবহার করে একটি string slice return করি।

এখন first_word call করলে আমরা একটিমাত্র মান ফেরত পাই, যা মূল ডেটার সঙ্গে বাঁধা। মানটি গঠিত slice-এর শুরুর বিন্দুর একটি reference আর slice-এর উপাদানের সংখ্যা দিয়ে।

second_word function-এর ক্ষেত্রেও slice return করা কাজ করবে:

এখন আমাদের কাছে একটি সরল API আছে, যাতে গোলমাল পাকানো অনেক কঠিন, কারণ compiler নিশ্চিত করবে যে String-এর ভেতরের reference-গুলো বৈধ থাকে। Listing 4-8-এর প্রোগ্রামের বাগটি মনে আছে, যেখানে আমরা প্রথম শব্দের শেষের index পেয়েছিলাম, কিন্তু তারপর string-টি খালি করে দেওয়ায় index-টি অবৈধ হয়ে গিয়েছিল? ওই কোড যৌক্তিকভাবে ভুল ছিল, কিন্তু সঙ্গে সঙ্গে কোনো error দেখায়নি। খালি করা string-এর সঙ্গে প্রথম শব্দের index ব্যবহারের চেষ্টা চালিয়ে গেলে সমস্যাগুলো পরে দেখা দিত। slice এই বাগকে অসম্ভব করে দেয় এবং আমাদের কোডে সমস্যা থাকলে অনেক আগেই তা জানিয়ে দেয়। যেমন:

borrowing-এর নিয়ম মনে করুন: কোনো কিছুর একটি immutable reference থাকলে একই সঙ্গে আমরা তার mutable reference নিতে পারি না। clear-কে যেহেতু String ছোট করে ফেলতে হয়, তাই এর একটি mutable reference দরকার। clear call-এর পরের println! word-এর reference ব্যবহার করে, তাই ওই জায়গাতেও immutable reference-টি সক্রিয় থাকতে হবে। Rust clear-এর mutable reference আর word-এর immutable reference-কে একই সময়ে থাকতে দেয় না, ফলে compile ব্যর্থ হয়। Rust শুধু আমাদের API ব্যবহার সহজই করেনি, compile time-এ পুরো এক শ্রেণির error-ও দূর করে দিয়েছে!

string literal হলো slice

মনে আছে, আমরা বলেছিলাম string literal binary-র ভেতরে রাখা থাকে। এখন slice সম্পর্কে জানার পর আমরা string literal ঠিকমতো বুঝতে পারি:

#![allow(unused)]
fn main() {
let s = "Hello, world!";
}

এখানে s-এর type হলো &str: এটি binary-র সেই নির্দিষ্ট জায়গাকে নির্দেশ করা একটি slice। এ কারণেই string literal immutable; &str একটি immutable reference।

parameter হিসেবে string slice

literal আর String মানের slice নেওয়া যায় জানলে first_word-এ আরও একটি উন্নতি করা যায়, আর তা হলো এর signature:

fn first_word(s: &String) -> &str {

আরও অভিজ্ঞ একজন Rustacean বরং Listing 4-9-এ দেখানো signature লিখবেন, কারণ এতে একই function &String মান আর &str মান দুটোর ওপরই ব্যবহার করা যায়।

fn first_word(s: &str) -> &str {
    let bytes = s.as_bytes();

    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }

    &s[..]
}

fn main() {
    let my_string = String::from("hello world");

    // `first_word` `String`-এর slice-এর ওপর কাজ করে, আংশিক হোক বা পুরো।
    let word = first_word(&my_string[0..6]);
    let word = first_word(&my_string[..]);
    // `first_word` `String`-এর reference-এর ওপরও কাজ করে, যা `String`-এর
    // পুরো slice-এর সমতুল্য।
    let word = first_word(&my_string);

    let my_string_literal = "hello world";

    // `first_word` string literal-এর slice-এর ওপর কাজ করে, আংশিক হোক বা
    // পুরো।
    let word = first_word(&my_string_literal[0..6]);
    let word = first_word(&my_string_literal[..]);

    // string literal যেহেতু আগে থেকেই string slice, তাই
    // slice syntax ছাড়াও এটি কাজ করে!
    let word = first_word(my_string_literal);
}

Listing 4-9: s parameter-এর type হিসেবে string slice ব্যবহার করে first_word function উন্নত করা

আমাদের কাছে একটি string slice থাকলে সেটি সরাসরি পাঠাতে পারি। একটি String থাকলে String-এর একটি slice বা String-এর একটি reference পাঠাতে পারি। এই নমনীয়তা deref coercion (স্বয়ংক্রিয় dereference-রূপান্তর)-এর সুবিধা নেয়, যে বৈশিষ্ট্যটি আমরা অধ্যায় 15-এর “Implicit Deref Coercions with Functions and Methods” অংশে আলোচনা করব।

String-এর reference-এর বদলে string slice নেওয়ার মতো করে function সংজ্ঞায়িত করলে কোনো কার্যকারিতা না হারিয়েই আমাদের API আরও সাধারণ ও কাজের হয়:

অন্যান্য slice

আপনি যেমন ভাবছেন, string slice শুধু string-এর জন্য। কিন্তু আরও একটি সাধারণ slice type আছে। এই array-টি দেখুন:

#![allow(unused)]
fn main() {
let a = [1, 2, 3, 4, 5];
}

যেমন আমরা একটি string-এর অংশ reference করতে চাইতে পারি, তেমনি একটি array-রও অংশ reference করতে চাইতে পারি। সেটা আমরা এভাবে করব:

#![allow(unused)]
fn main() {
let a = [1, 2, 3, 4, 5];

let slice = &a[1..3];

assert_eq!(slice, &[2, 3]);
}

এই slice-এর type হলো &[i32]। এটি string slice-এর মতোই কাজ করে, অর্থাৎ প্রথম উপাদানের একটি reference আর একটি দৈর্ঘ্য রেখে। অন্যান্য নানা ধরনের collection-এর জন্য আপনি এই ধরনের slice ব্যবহার করবেন। এই collection-গুলো নিয়ে আমরা অধ্যায় 8-এ vector নিয়ে কথা বলার সময় বিস্তারিত আলোচনা করব।

সারসংক্ষেপ

slice হলো এক বিশেষ ধরনের reference, যা string বা vector-এর মতো কোনো ক্রমের উপ-পরিসরকে নির্দেশ করে। runtime-এ একটি slice প্রকাশ করা হয় একটি “fat pointer” (metadata-সহ pointer) হিসেবে, যাতে থাকে পরিসরের শুরুর একটি pointer আর পরিসরের দৈর্ঘ্য। index-ভিত্তিক পরিসরের তুলনায় slice-এর একটি সুবিধা হলো, ব্যবহারে থাকা অবস্থায় slice অবৈধ হয়ে যেতে পারে না।
